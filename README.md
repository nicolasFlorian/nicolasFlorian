## Open source

### [shopify-preact-sections](https://github.com/nicolasFlorian/shopify-preact-sections)

The Vite plugin behind the Belly Moda theme. Describe a Shopify section once in TypeScript and it generates the Liquid file, the typed props and the Preact mount code. Optional shells compile JSX to Liquid, so crawlers get real HTML before any JavaScript runs.
